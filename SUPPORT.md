# Support

This candidate is for local evaluation. There is no on-call service, guaranteed
response time, paid support contract or stable compatibility promise.

For non-sensitive bugs, use a repository issue with the source revision,
OS/browser, clean reproduction and sanitized error category. Follow SECURITY.md
for vulnerabilities. Model providers, operating systems and reference hardware
have their own licenses/support channels. Do not post raw audio, personal
transcripts, environment files, keys or flash dumps.

The scripted Pages demo is supported without hardware. The authenticated client
targets desktop Chromium and Firefox, with synthetic acceptance recorded per
candidate; WebKit demo coverage is separate from actual microphone acceptance.
Hardware, phone audio, charging, OTA and soak remain experimental until their
recorded gates pass. A mode compiling does not make it supported.
